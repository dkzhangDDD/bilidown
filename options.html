bilidown 设置

密钥保存在当前 Chrome 配置中。音频只会发送给你选择的语音识别服务， YouTube 字幕请求会发送给 Supadata，字幕和视频上下文会发送给你选择的 AI 服务。本扩展没有开发者服务器或数据分析。

B站识别

bilidown 会先检查 B 站原生字幕；只有没有可用字幕时，才使用所选的语音识别服务。

bilinote 会下载当前B站音轨，上传到百炼 48 小时临时空间，并使用 Fun-ASR 异步识别生成带时间戳字幕，适合任意时长。 获取百炼 API Key。

minimasr-1.0 直接 multipart 上传音轨，无需中转，延迟低。 限制：单文件 ≤ 50 MB 且 ≤ 500 秒；长视频会被拒绝，请改用阿里百炼。

复用上方「AI 服务」中填写的 MiniMax Key，无需在此重复填写。

走本地 OpenAI 兼容的 /v1/audio/transcriptions，也兼容 whisper.cpp 的 /inference。使用 whisper.cpp 时请加 --convert 并装 ffmpeg，因为 B 站音轨是 M4A。

本地 Whisper 启动指引
  1. 装好 Python 3.10+，pip install -r local-whisper\requirements.txt。
  2. 运行 local-whisper\download_model.ps1 下载 Whisper 和中文标点模型。
  3. 运行 powershell -File local-whisper\start.ps1 启动服务。
  4. 打开 http://127.0.0.1:9000/health，status 与 punctuation_status 同时为 ready 即就绪。
  5. 在设置页选「本地 Whisper」，地址填 http://127.0.0.1:9000/v1/audio/transcriptions，模型名称填 large-v3-turbo，API Key 留空。

地址必须使用 http://localhost 或 http://127.0.0.1。音频只发送到本机端口， 不会经过开发者服务器。

YouTube识别

用于获取带时间戳的 YouTube 原生字幕。 创建 Supadata 账号并获取密钥。Supadata 会在引导流程中生成密钥。

AI 服务

bilidown uses DeepSeek V4 Flash for overviews, explanations, translation, and note polishing. Create a DeepSeek API key.

When you use AI features, DeepSeek receives the video transcript and relevant video context. Review DeepSeek's terms and pricing before saving.

bilidown 使用 MiniMax M3 生成概览、总结、翻译与润色。包月 Token Plan 请在MiniMax 开放平台「订阅管理 > Token Plan」查看订阅 Key。

使用 AI 功能时，MiniMax 会收到视频字幕及相关视频上下文。保存前请查看 MiniMax 的服务条款和价格。

需要服务商提供 OpenAI 兼容的 /chat/completions 接口。Base URL 以 /v1 结尾时也会自动拼接。
