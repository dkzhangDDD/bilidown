# Privacy

bilidown has no account system, analytics, telemetry, advertising, or developer-operated server.

- The extension reads public video metadata and, when available, native subtitle tracks from Bilibili and YouTube.
- Your API keys, notes, settings, and recent cache entries are stored in `chrome.storage.local`.
- **AI summaries** are generated by the chat provider you select in Settings (DeepSeek, MiniMax, or any OpenAI-compatible service). Only the relevant transcript and video context are sent.
- **Speech-to-text** is generated by the ASR provider you select in Settings. Three options are built in:
  - **Aliyun Bailian Fun-ASR** (default): the audio is uploaded to a 48-hour Aliyun OSS staging bucket and processed asynchronously.
  - **minimasr asr-1.0**: the audio is uploaded directly to minimasr via a single multipart POST (no staging bucket, but limited to 50 MB / 500 s per request).
  - **Local Whisper**: the audio is sent only to an HTTP endpoint on `localhost` or `127.0.0.1` that you run yourself; bilidown does not operate or receive data from that service.
  - If no ASR provider is configured, bilidown falls back to native Bilibili subtitles.
- **YouTube transcripts** are requested from Supadata using `mode=native`. Only the canonical YouTube URL and your Supadata API key are sent; YouTube audio is not downloaded or uploaded.
- No API key is included in the source code or release package.

Bilibili, YouTube, Supadata, DeepSeek, MiniMax, Aliyun Bailian, and minimasr each process requests under their own terms and privacy policies. Remove all local extension data from Settings before uninstalling if you do not want Chrome to retain it.
